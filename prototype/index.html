智枢 前端重构原型 v1

智枢 · 双端合一、统一登录、一键切换

本原型用于确认合并后的交互与视觉基准：React 管理后台与静态 HTML 用户端合并为一个 Vue3 + Ant Design Vue 工程， 全局仅保留一个登录页，登录后默认进入智能对话，并可无感切换到管理后台 —— 管理端覆盖智能体编排与私有知识库配置。

Vue 3.4 + TypeScript ant-design-vue 4 Vite 5 · Pinia · vue-router LogicFlow 编排画布

核心页面（5 页）

点击卡片进入对应原型页，页面之间可直接互相跳转，模拟真实操作链路。

01 · 统一登录页

/login

深色渐变品牌区 + 玻璃拟态表单卡，支持密码明文切换与 admin 快捷登录，登录成功跳转 /chat。

02 · 用户端智能对话

/chat（默认落地）

会话列表 + 智能体/步数/案例选择 + 过程与结果双栏 + Markdown 渲染，顶栏一键进入管理后台。

03 · 管理端数据总览

/admin/dashboard

4 张指标卡 + 7 日趋势折线 + 模型调用占比 + 最近动态，侧边菜单按编排/资源/知识库分组。

04 · 列表范式页

/admin/client-management

查询区 + 操作区 + 吸顶表头表格 + 分页 + 新增/编辑弹窗 + 删除二次确认，10 个模块复用同一范式。

05 · 智能体编排画布

/admin/agent-config

LogicFlow 点阵画布 + 节点面板 + 连线 + 小地图 + 右侧属性抽屉，保存时序列化为后端兼容 JSON。

其余 8 个管理页

智能体列表、客户端 API、顾问、模型、系统提示词、MCP 工具、RAG 知识库配置，全部复用第 04 页的列表范式，仅查询字段与表单字段不同，本次不单独出图。

核心交互链路

1

一次登录，写入统一登录态

调用 POST /api/v1/admin/admin-user/login，将 token 与用户信息写入 Pinia 并持久化到 localStorage，刷新后仍保持登录。

2

默认落地用户端

登录成功后跳转 /chat，对话通过 SSE 流式呈现分析 / 执行 / 监督 / 总结四个阶段。

3

免二次登录切换管理端

点击「进入管理后台」直达 /admin/dashboard，复用同一 token，无需再次输入密码；管理端亦可随时返回对话页。

辅助信息12px / 400

原型说明

  • 本原型为静态 HTML + Tailwind 实现，仅用于确认视觉与交互，不含真实接口调用；按钮点击以轻提示模拟结果。
  • 正式实现将落在新工程 ai-agent-station-ui（Vue3 + Ant Design Vue 4 + Pinia + vue-router + LogicFlow），后端 Java 代码零改动。
  • 登录后不做角色区分：任一账号登录即可访问用户端与管理端，与「两端绑定同一个账号」的约定一致。
  • 画布页保留了后端契约提示：持久化 JSON 的连线字段为 sourceNodeID / targetNodeID，与 LogicFlow 原生字段不同，迁移时由适配器双向转换。
